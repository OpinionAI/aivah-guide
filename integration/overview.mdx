# Integration Overview

AIVAH provides comprehensive integration capabilities that allow you to connect your AI agents with various platforms and services. The Integrations workspace groups the following pages under `Side nav → Integrations`:

| Page | Path | Purpose |
|---|---|---|
| **AI Drive** | `/integrations/ai-drive` | Gallery of every image, video, slide, document, and web result generated by your agents. |
| **MCP** | `/integrations/mcp` | Composio-powered MCP tools your agent can call (Gmail, Calendar, Notion, Linear, etc.). |
| **Telephony** | `/integrations/telephony` | Twilio phone-number setup, with optional SIP trunk support. |
| **Channels** | `/integrations/channels` | Native Slack and WhatsApp connectors. |
| **Manage Memory** | `/integrations/manage-memory` | View, edit, and export the agent's long-term memory. |
| **Tasks** | `/integrations/tasks` | Cron jobs and heartbeat tasks created by you or your agent. |

## 🎯 Core Integration Areas

### 1. Telephony Integration
Connect your AI agents to phone systems for voice-based interactions:
- **Twilio Integration**: Full-featured telephony platform supporting both inbound and outbound calls
- **Bring Your Own SIP Trunk**: Optional Twilio termination SIP URI for advanced routing
- **Real-time Voice Processing**: Natural conversation flow with configurable voice options
- **Call Management**: Complete call logging, transcription, and analytics

### 2. Channels (Slack & WhatsApp)
Native connectors that let an agent respond inside the chat tools your audience already uses:
- **Slack**: App-manifest based setup with `/aivah` slash command, bot token, and signing secret
- **WhatsApp**: QR-pairing flow with Refresh / Power controls and 2-second status polling
- **Per-channel Agent + LLM**: Each card pins an agent and model so behaviour is consistent

### 3. Memory Management
Persistent memory system that allows your agents to remember key information:
- **Cross-Platform Memory**: Agents remember user information across web, telephony, and channels
- **Manage Memory Page**: Inline edit / delete on every row plus **Download CSV** export
- **User Control**: Full visibility and control over stored memories

### 4. App Connectivity (MCP)
Seamless integration with external applications and services:
- **Composio MCP**: One-click OAuth connectors with automatic verification (*"Account verified and connected!"*)
- **Active counter**: Each search bar shows how many tools are enabled vs the plan limit (`X/3 Active` by default)
- **Wide App Support**: Connect to popular productivity tools like Gmail, Calendar, Notion, Linear, Slack, GitHub, and more
- **Custom Integrations**: Build your own integrations using our MCP framework

### 5. Tasks (Cron & Heartbeat)
Automate scheduled and recurring work without leaving the chat:
- **Cron Jobs**: Schedule any agent action with a cron expression. Includes inline **Run now** and **Delete** controls.
- **Heartbeat**: Background tasks that flag themselves if their heartbeat stops coming in.

### 6. AI Drive Media Library
Centralized storage for generated images, videos, slides, documents, and web results:
- **Automatic Capture**: Every asset created in the Hub or Productivity workspace is saved instantly
- **Tabs**: Image, Video, Files (with sub-tabs for Slides, Document, Webresults)
- **Easy Export**: Preview, open in new tab, and download files for sharing or reuse in other channels

## 🚀 Getting Started

1. **Choose Your Integration Type**: Select from telephony, memory, or MCP-based app integrations
2. **Configure Your Agent**: Set up voice, knowledge base, and LLM model preferences
3. **Connect Your Services**: Authenticate and configure your external services
4. **Deploy and Test**: Launch your integrated workflow and monitor performance
